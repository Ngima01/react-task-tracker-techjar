# Mini Task Tracker – React

## Features
- Add, edit, delete tasks
- Filter tasks (All / Pending / Done)
- Debounced search
- Sorting by name or due date
- Persistent storage using localStorage (mock API)

## Tech Stack
- React (Hooks)
- Plain CSS
- LocalStorage

## How to Run Locally
npm install
npm run dev

## Notes
This project follows clean component-based architecture and React best practices.
